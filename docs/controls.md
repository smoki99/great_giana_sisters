# Controls — Mia in Candy Land

| Key | Action |
|---|---|
| `W A S D` / arrow keys | Move; camera is fixed, so `W` is always screen-up (into the depth), `D` screen-right |
| `SPACE` | Jump; press again in mid-air for the spin double-jump |
| `ENTER` | Start / confirm / back to title |
| `1` / `2` | (on title) pick Mia or Lina |
| `M` | Music on/off (SFX always play) |

Gamepad: none — keyboard only in this build.

## Game rules quick sheet

- Collect **gems** (+1 counter) and the spinning **diamond** → 10 s power: run faster, kills enemies on touch.
- **Stomp** enemies from above (falling feet onto their heads) — side contact costs a life.
- **Spring pads** launch you to high ledges; **flag** sets your respawn point.
- Falling off the map or the 200 s timer running out costs a life; 0 lives = game over.
- Reach the **goal gate** to win.
