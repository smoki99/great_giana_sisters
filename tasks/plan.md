# Implementation Plan: Giana-like Sisters 3D (browser demo)

Grounded in `SPEC.md` (approved-pending answers below) and `CAPABILITY-MAP.md`. Toolchain phase is **done and verified** (Godot 4.6 headless + Web templates, Blender 4.5.16 headless, Bun scripts, LSP/MCP/browser smoke all green — see `AGENTS.md`).

## Overview

One overworld level ("Sugarwood Glade"), Mario-64-style analog 3D movement with Giana-1 level structure (gems, 200 s timer, spring pads, diamond power-up, one checkpoint, goal gate), Mia playable / Lina reskin, all figures generated by headless Blender scripts, shipped as a static WASM zip playable from `index.html`.

## Architecture decisions

- **Pure logic in GDScript `RefCounted` classes** (state machine, gem/timer/lives, power-up, spring physics): unit-tested headless via `godot -s tests/run_tests.gd`; scenes stay thin glue. No gtest needed.
- **Assets are code**: `tools/blender/build_assets.py` regenerates every `.glb` + preview PNG deterministically; repo never hand-edits `assets/`.
- **Vertical slices**: movement-cam blockout (Phase 2) runs on grey boxes, so it does not block on Phase 1 asset acceptance.
- **Test mirror in Bun** only for non-Godot TS scripts; game logic tests run inside Godot (single source of truth).
- **Ship format**: `build/giana3d-web-<ver>.zip` + one serve command (COOP/COEP server `scripts/serve-web.ts`).

## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| Fontconfig warning in Godot wrapper (fonts for editor only) | Low | runtime uses its own fonts; ignore unless text renders wrong in browser |
| WASM threads/COOP-COEP friction in some browsers | Med | export both templates; serve-web sends headers; nothreads fallback preset |
| Cycles-CPU preview time (19 figures) | Low | 32 spp stills, parallel per-figure invocations |
| Feel tuning (jump arc, cam) can't be checked headless-only | Med | E2E screenshots + input probe; tune constants from unit tests |
| Rig/anim quality ceiling via bpy scripting | Med | keep figures chunky-simple; visual gate at T10 before game rework |
